# 📖 The Lexicon: AI Oratory & Vocabulary Mastery

An intelligent vocabulary acquisition and rhetorical coach powered by the **Anthropic Claude API**. Designed to elevate public speaking, debate oratory, and nuanced prose writing through contextual critique.

## ⚡ Core Modules

- **Contextual Synonyms & Nuance Engine**: Replaces pedestrian vocabulary with precise, emotionally resonant phrasing graded by rhetorical register.
- **Speech Delivery Feedback**: Evaluates cadence, ethos, pathos, and logos in drafted speech text.
- **Spaced Repetition Lexicon**: Tracks newly encountered words across active writing sessions.

---

## 🛠️ Stack

- **Frontend**: React, TypeScript, Tailwind CSS
- **AI Integration**: Claude API (`claude-3-5-sonnet`)
- **Speech**: Web Speech API for voice prompts

---

## 🚀 Setup

```bash
git clone https://github.com/Demmonics/the-lexicon.git
cd the-lexicon

npm install
cp .env.example .env # Add your ANTHROPIC_API_KEY
npm run dev
```

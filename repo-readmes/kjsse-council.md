# 🏛️ KJSSE Students' Council Web Portal

The official, cyber-kinetic web application for the **K.J. Somaiya College of Engineering Students' Council**. Built to serve as the unified digital hub for student initiatives, departmental bodies, and flagship college festivals.

## ⚡ Architecture & Modules

- **Kinetic 3D Hero Canvas**: Interactive WebGL mesh environment built with Three.js capturing the institutional energy of Somaiya.
- **Council Leadership & Secretariat Directory**: Dynamic directory displaying student council members, departments, and active portfolios.
- **Event Registrations & Live Updates**: Real-time event ticketing and updates for collegiate festivals (Abhiyantriki, Symphony, Skream).
- **Hardened API Gateway**: Express.js server providing authenticated administrative endpoints and data management.

---

## 🛠️ Stack & Technologies

- **Frontend**: Vite, React 18, TypeScript, Three.js, Lucide Icons, Tailwind CSS
- **Backend**: Node.js, Express.js, MongoDB / Supabase
- **Hosting**: Deployed on Railway / Vercel

---

## 🚀 Local Setup

```bash
git clone https://github.com/Demmonics/stuco_website.git
cd stuco_website

# Install dependencies
npm install

# Start Vite server
npm run dev
```
